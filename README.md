Inspirado no já existente programa Midikey2Key, feito para resolver um problema de compatibilidade com o PSR-E473. Foi desenvolvido para funcionar com o meu teclado musical, podendo não servir para outros teclados.

---

iniciar.bat                                -> Inicia o programa (wow)

[1] Iniciar tradução (MIDI -> caractere)   -> Inicia a tradução dos sinais MIDI do E473 para caracteres de teclado de computador
[2] Monitor                                -> Abre o monitor das traduções sem executar o produto delas
[3] Sair                                   -> Sai do programa (quem diria)
